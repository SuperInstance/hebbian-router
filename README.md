# hebbian-router

**Hebbian routing for agent communication** — "neurons that fire together, wire together" applied to agent message routing. Routes strengthen with use and decay with disuse.

## What This Gives You

- **Adaptive routing** — message paths strengthen proportionally to usage
- **Decay curves** — unused routes fade over configurable half-lives
- **Emergent topology** — network structure self-organizes from traffic patterns
- **Pure Python** — zero external dependencies

## Installation

```bash
pip install hebbian-router
```

## How It Fits

Part of the SuperInstance agent coordination research. Explores whether Hebbian learning principles can produce efficient, adaptive routing in agent fleets without centralized control.
